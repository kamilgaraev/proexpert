# Восстановление распознавания смет — 9 сентября 2026

При загрузке Excel файл сохранялся, но определение типа завершалось пустым HTTP 500 через 30 секунд. На локальной копии файла размером 386 449 байт первый обработчик определял Гранд-Смету с уверенностью 100%, после чего продолжались остальные проверки с повторной загрузкой всей книги. Суммарный замер обработчиков до исправления — около 58 секунд; после исправления полный выбор обработчика — 0,96 секунды. Это локальные измерения, а не гарантия времени на любом сервере.

## Изменение поведения

- После результата 100% дальнейший перебор останавливается; при меньшей уверенности сохраняется поиск лучшего результата и прежний порядок при равенстве.
- Для определения формата загружаются только нужные строки. Проверка метки шаблона читает свойства без строк. Полное чтение позиций не ограничивается.
- Выборка использует сохранённые в Excel результаты формул, чтобы не пересчитывать их по неполной книге.
- Ошибка получения файла и ошибка распознавания сохраняют статус `failed` и безопасное сообщение. Повторная попытка очищает предыдущую ошибку.
- В журнал попадают начало, обработчик, завершение, длительность и исключение. Контроллер передаёт неожиданные исключения стандартному обработчику отчётов об ошибках.
- Перед началом сохраняется срок выполнения. После принудительного завершения процесса просроченная попытка помечается прерванной при следующем запросе статуса. Успешная попытка и новый повторный запрос защищены условиями обновления. Без запроса статуса отдельного фонового обнаружения нет; SIGKILL невозможно поймать обычным catch.
- Старые сессии без новых диагностических полей автоматически не изменяются.

## Проверки

- Четыре модульных теста: остановка после точного совпадения, выбор при неполном совпадении, ограниченная выборка и метаданные, формулы и полное чтение.
- Пять тестов в разрешённом PostgreSQL-контуре: ошибка хранилища, ошибка распознавателя с успешным повтором, неподдерживаемый формат, восстановление прерванной попытки, защита активного и завершённого распознавания.
- Синтаксис изменённых PHP-файлов, PHPStan/Larastan с изолированной загрузкой стандартных провайдеров Laravel (без несвязанных внешних сервисов).

## Файлы

- `EstimateImportService.php`: состояние, диагностика, восстановление прерванного распознавания.
- `ImportFormatDetector.php`: остановка перебора и информация о текущем обработчике.
- `SpreadsheetSampleLoader.php`, `SpreadsheetTableReader.php`: ограниченное чтение и готовые значения формул.
- `GrandSmetaRuntimeBridge.php`, `MostTemplateHandler.php`: использование ограниченного чтения и освобождение книги.
- `EstimateImportController.php`: передача исключения стандартному обработчику.
- `lang/ru/estimate.php`: сообщение о прерывании.
- `ImportDetectionRecoveryTest.php`, `ImportDetectionStateTest.php`: регрессионные проверки.

Изменения схемы БД и конфигурации развёртывания не требуются.
