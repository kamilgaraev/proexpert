# Помощник МОСТ: смысловой выбор инструкций и диалог

## Поведение

Пользователь задаёт вопрос своими словами в админке, личном кабинете или мобильном приложении. Сервер получает опубликованные инструкции через существующий фильтр доступа для текущего пользователя и контура. Qwen 3.5 Flash через Timeweb сопоставляет намерение с полным содержанием этих инструкций и выбирает до шести источников. Затем отдельный вызов модели составляет краткий ответ только по выбранным источникам. Совпадение слов вопроса с заголовками не требуется.

При неоднозначности возвращается конкретный уточняющий вопрос. При отсутствии фактов возвращается сообщение об отсутствии ответа. Сервер проверяет идентификаторы источников на обоих этапах. История служит только контекстом намерения, не источником фактов или прав.

## API и интерфейсы

POST /knowledge-hub/assistant сохраняет существующие authenticated маршруты каждого контура. question: 1–1000 символов; context_key: до 120; необязательная history: до восьми сообщений user/assistant по 2000 символов. Системные роли и дополнительные поля сообщений запрещены.

Ответ сохраняет совместимые status answered / insufficient_knowledge и sources с id/title. Дополнительный needs_clarification отличает уточнение от отсутствия ответа. Старые версии мобильного клиента продолжают понимать ответ.

Клиенты показывают четыре последних пары вопрос/ответ и передают их в следующий запрос. После успеха поле ввода очищается. Ошибка сохраняет разговор и вопрос для повтора. Смена раздела, закрытие экрана или новый разговор сбрасывают состояние; запросы отменяются при уходе. История хранится в памяти экрана.

## Стоимость и границы

На 08.09.2026 каталог https://timeweb.cloud/services/ai-gateway указывает dashscope/qwen3.5-flash: 14 ₽/млн входящих и 52 ₽/млн исходящих токенов. GLM 4.7 FlashX дешевле по входу (9,45/54 ₽), но при проверке в production дважды не ответил за 20 секунд; для помощника выбран Qwen. Модель используется только помощником инструкций; остальные AI-сценарии сохраняют свою маршрутизацию. enable_thinking=false, максимум 900 выходных токенов и 20 секунд на этап. Оба вызова учитываются в статистике использования, месячный лимит применяется к пользовательскому обращению.

Для текущей небольшой базы используется выбор источников моделью, без векторного индекса. Каталог читается постранично, без обрезки инструкций. Защитный предел — 120 доступных статей и 160000 символов содержимого и заголовков на запрос. Превышение возвращает недоступность, а не ответ по случайному подмножеству. Перед ростом базы до этого предела требуется отдельный индекс поиска.

## Проверки и выпуск

Регрессионные тесты: свободная формулировка без слов из статьи; уточнение на обоих этапах; короткое продолжение с историей; неизвестный вопрос; недопустимые источники; валидация истории; повтор после ошибки; новый разговор и смена раздела. PHPStan, PHP lint, TypeScript, ESLint и Flutter analyze по области изменений. Выпуск через существующие PR/CI/CD; затем проверка диалога в браузере. Для мобильной версии статус RuStore MODERATION считается завершённым деплоем по решению пользователя.
