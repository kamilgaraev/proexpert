# Русское отображение свойств BIM

Словарь находится в `lang/ru/design_bim_labels.php`. Сервер формирует русские подписи для админки и мобильного приложения через `DesignBimLocalizationService`. Исходные IFC-файлы, индекс элементов, ключи свойств и значения не перезаписываются. В личном кабинете отдельного BIM-интерфейса сейчас нет.

## Контракт API

Список элементов получает дополнительное nullable-поле `category_label`. Исходное `category` сохраняется. Карточка элемента дополнительно получает `display`:

```json
{
  "locale": "ru",
  "schema_version": 1,
  "fields": [
    {
      "path": ["properties", "Tekla Common", "Top elevation"],
      "label": "Свойства · Общие свойства Tekla · Верхняя отметка",
      "value": "+13.913"
    }
  ]
}
```

`path` содержит исходные сегменты и служит устойчивым идентификатором строки. Одинаковые русские подписи не приводят к потере свойств. Массивы разворачиваются с исходными индексами. Отсутствующие значения и пустые коллекции получают текст из словаря; ноль и false сохраняют своё значение.

Новые клиенты показывают `display`, а при его отсутствии используют прежний контракт. Локальный словарь админки оставлен только для совместимости с предыдущим сервером при выпуске.

## Границы перевода

Словарь содержит названия полей, типовые группы IFC, свойства Tekla, IFC-категории, известные материалы и перечислимые значения. Ключи подписей сопоставляются без учёта регистра и разделителей. Категории и текстовые значения переводятся только при полном словарном совпадении без учёта регистра и окружающих пробелов. Пунктуация и кириллица не удаляются из значений.

Названия элементов, GUID, обозначения, профили и марки сохраняются. Для материалов переводятся только известное название материала или непосредственное значение массива материалов. Произвольные вложенные поля не переводятся по контексту группы. Неизвестные свойства и авторские тексты остаются исходными; автоматического перевода через внешние сервисы нет. Расширять покрытие нужно в серверном словаре.

## Просмотр без сети и выпуск

Manifest offline-пакета получает дополнительное поле `localization` с версией схемы и нормализованным серверным словарём. Геометрия, файл свойств, их размер, SHA-256 и generation сохраняются. Приложение сохраняет словарь вместе с manifest и строит русское представление выбранного элемента без сети.

Для ранее сохранённой модели словарь обновляется при следующем открытии с доступом к сети. Если словаря ещё нет, старый пакет остаётся доступен в исходном виде. Пересоздание модели и повторная загрузка геометрии не нужны.

Порядок выпуска: сервер, затем админка и новая версия приложения. Старые версии приложения продолжают работать с исходными полями. Для русского отображения на телефоне нужна установка обновлённого приложения. Миграции и новая конфигурация не требуются.
