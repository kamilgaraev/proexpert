# Акт списания складских материалов

## Проблема

В истории прямых списаний пользователю предлагаются формы М-11 и М-15. М-11 оформляет внутреннее движение материалов, а М-15 — отпуск материалов сторонней организации. Потеря, повреждение, утилизация и корректировка по инвентаризации являются другими фактами хозяйственной жизни и должны оформляться отдельным первичным документом.

## Решение

- Для прямого списания формировать «Акт списания материальных ценностей» в XLSX.
- В акт включать организацию, номер и дату, склад, объект, основание, категорию операции, материалы, единицы измерения, количество, цену, сумму и поля подписантов.
- В истории прямых списаний показывать только действие «Скачать акт списания».
- Не предлагать М-11 и М-15 для потери, повреждения, утилизации и корректировки по инвентаризации.
- Не ослаблять изоляцию организаций: документ формируется только для движения текущей организации.
- Не считать сформированный файл подписанным документом. Это заполняемый шаблон первичного документа; состав подписантов утверждает руководитель организации.

## API-контракт

`GET /api/v1/admin/warehouses/movements/{id}/export-write-off-act`

Успех: стандартный `AdminResponse` с временной S3-ссылкой в `data.url`.

Ограничения:

- требуется право `warehouse.write_offs`;
- движение принадлежит текущей организации;
- тип движения — `write_off`;
- категория — `loss`, `damage`, `disposal` или `inventory_adjustment`.

## Проверки

- регрессионный backend-тест состава XLSX и изоляции организаций;
- проверка отказа для несовместимого движения;
- frontend-тест единственного понятного действия и корректного открытия файла;
- PHPStan/Pint, TypeScript, ESLint/Prettier и целевые тесты.
