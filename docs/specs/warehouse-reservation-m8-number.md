# Бизнес-номер М-8 при создании резерва

## Цель

Дать владельцу организации возможность указать человекочитаемый номер лимитно-заборной карты при создании складского резерва и видеть его в карточке. Внутренний ID записи не используется как номер документа.

## Контракт

- `POST /api/v1/admin/advanced-warehouse/reservations` принимает необязательный `document_number`: строка до 100 символов.
- Пробелы по краям удаляются; пустая строка сохраняется как отсутствие номера.
- Значение хранится в `asset_reservations.metadata.document_number`, поэтому миграция не требуется.
- Ответ создания и реестра содержит `document_number: string|null`.
- Экспорт М-8 использует этот номер; при отсутствии сохраняет существующую подпись «Без номера».

## UI

- Форма создания содержит необязательное поле «Номер карты М-8» с ограничением 100 символов и понятным пояснением.
- Карточка резерва показывает «Номер карты М-8» и значение либо «Без номера».
- Технический ID резерва не показывается пользователю.

## Проверки

- API сохраняет нормализованный номер и возвращает его в payload.
- Значение длиннее 100 символов отклоняется валидацией.
- UI отправляет номер, сбрасывает его вместе с формой и отображает полученное значение.
