# Архив складских активов

## Назначение

Деактивация карточки актива не удаляет складскую историю и не должна быть безвозвратным действием. Владелец организации должен видеть архивные карточки и возвращать ошибочно деактивированные активы в действующий каталог.

## API-контракт

- `GET /api/v1/admin/assets` принимает `status=active|inactive|all`; без параметра возвращает только действующие активы.
- `POST /api/v1/admin/assets/{id}/activate` восстанавливает архивную карточку только в текущей организации.
- Неизвестный статус возвращает ошибку валидации, чужой актив — `404` без раскрытия данных другой организации.

## Состояния интерфейса

- Действующие: доступны учёт, фотографии и деактивация.
- Архив: карточки явно помечены и доступны только для просмотра и восстановления.
- Все: действующие и архивные карточки показаны вместе с различимым статусом.

## Проверки

- Фильтрация по каждому состоянию и обратная совместимость значения по умолчанию.
- Восстановление своей карточки и запрет восстановления карточки другой организации.
- Понятные подписи фильтра, статуса и действия восстановления.
