# Проведение платежа с сохранённым обоснованием превышения бюджета

## Проблема

При редактировании платёжного документа владелец может подтвердить превышение бюджетного лимита и указать обоснование. МОСТ сохраняет это обоснование, однако при последующей отправке документа на согласование повторно требует тот же текст, если клиент не продублировал его в запросе отправки.

## Ожидаемый контракт

- Отправка документа принимает новое `budget_override_reason`, если пользователь решил уточнить обоснование.
- Если новое значение не передано, используется ранее сохранённое и принятое обоснование документа.
- Пустое и ранее не сохранённое обоснование по-прежнему блокирует превышение лимита.
- Проверка права `budgeting.limits.override`, аудит исключения и резервирование бюджета сохраняются.

## Проверка

- HTTP-регрессия: документ с сохранённым обоснованием превышения отправляется без повторного ввода текста.
- Негативный существующий контракт: превышение без права или без какого-либо обоснования остаётся запрещено.
