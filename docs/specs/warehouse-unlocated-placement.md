# ISSUE-089: размещение нераспределённого складского остатка

## Проблема

Приёмка закупки может создать остаток без адресной ячейки. Склад показывает количество без адреса, но владелец не может штатно разместить его: межскладское перемещение требует исходную ячейку и не предназначено для этой операции.

## Контракт

`POST /api/v1/admin/warehouses/operations/place`

Вход: ключ идемпотентности, склад, материал, целевая ячейка, количество, необязательные номер документа и основание.

Операция:

- выбирает только доступные партии без `cell_id` в указанном складе и организации;
- поддерживает частичное размещение и FIFO по партиям;
- не использует уже адресованный остаток при нехватке неразмещённого;
- атомарно уменьшает остаток без ячейки и увеличивает остаток целевой ячейки;
- создаёт связанную нейтральную пару движений с категорией `placement`, чтобы UI отличал размещение от межскладской передачи;
- не создаёт приход или расход в аналитике общего остатка склада, потому что меняется только адрес хранения;
- повтор того же запроса безопасно возвращает прежний результат, а повтор ключа с иными данными отклоняется.

## UI-состояния

В реестре остатков материал с количеством без ячейки должен явно показывать предупреждение и действие «Разместить». Диалог показывает доступное неразмещённое количество, выбирает только активную доступную ячейку того же склада, допускает частичное количество и после успеха обновляет остатки.

## Проверки

- успешное частичное размещение;
- неизменность адресованного остатка источника;
- отказ при превышении неразмещённого количества;
- защита от чужого склада, материала или ячейки;
- идемпотентный повтор и конфликт ключа;
- типизация и UI-тест диалога.
