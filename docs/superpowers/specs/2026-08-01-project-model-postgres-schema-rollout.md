# PostgreSQL-схема цифровой модели проекта

## Ограничения данных

Таблица `estimate_generation_project_model_entities` принимает только семь видов сущностей: помещение, стена, проём, размер, таблица, конструктивный элемент и объём. Общая структура JSON, тип сущности, стабильный ключ, размер и уровень уверенности проверяются ограничениями строки. Семантика каждого из семи видов, включая обязательные поля, числовые значения, точки, полигоны, колонки и строки таблицы, проверяется триггером `eg_project_model_entity_payload_guard_trg` до вставки или обновления. Это исключает подзапросы из PostgreSQL `CHECK` и не допускает частично заполненные записи при прямом доступе к базе.

При привязке доказательства триггер `eg_project_model_evidence_binding_guard_trg` блокирует запись доказательства через `FOR UPDATE`. Пока действует блокировка, он повторно сверяет активность, версию источника, версию аннулирования и принадлежность доказательства указанной версии модели в `estimate_generation_building_model_evidence`.

## Порядок развёртывания

Сначала применяется миграция `2026_08_01_000150_add_project_model_projection_scope_indexes`. Она не выполняется в транзакции: перед созданием проверяет дубли, ограничивает ожидание блокировок, создаёт два уникальных индекса через `CREATE UNIQUE INDEX CONCURRENTLY` и проверяет их состояние и определение при повторном запуске. Невалидный индекс от прерванного запуска удаляется конкурентно и создаётся заново; несовпадающее определение или дубли требуют ручного разбора и не маскируются.

Затем применяется `2026_08_01_000200_create_estimate_generation_project_model_tables`. Его составные внешние ключи используют уже созданные уникальные индексы исходных таблиц. Поэтому в этой миграции нет блокирующего `ALTER TABLE ... ADD UNIQUE`.

Откат выполняется в обратном порядке одного пакета миграций: сначала удаляются таблицы проекции из `000200`, затем конкурентно удаляются индексы из `000150`. Нельзя откатывать `000150`, пока таблицы `000200` существуют: PostgreSQL корректно отклонит удаление индекса, используемого их внешними ключами.
