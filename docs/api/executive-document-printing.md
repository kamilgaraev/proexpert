# Подготовка и печать исполнительной документации

Базовый путь: `/api/v1/admin/executive-documentation`. Доступ проверяется по текущей организации, проекту и разрешению ИТД. Чужой документ скрывается ответом 404. Наличие файла не означает приёмку работ, комплектность ИД или действительность подписи.

| Операция | Запрос | Результат |
| --- | --- | --- |
| Печать сохранённой версии | `GET /versions/{versionId}/print?template_version=344-369-v1` | PDF из снимка выбранной версии; исходный файл не изменяется |
| Подготовка новой версии | `POST /documents/{documentId}/prepare` | Новая черновая версия с PDF и `origin=generated_preparation` |
| Комплект переданной версии | `GET /transmittals/{transmittalId}/package` | ZIP исходных файлов из манифеста передачи, `registry.json` и печатный `registry.html` |
| Связь с юридическим архивом | `POST /versions/{versionId}/legal-archive` | Идентификаторы документа и версии архива, состояние файла; подпись автоматически не регистрируется |

Для подготовки обязательны `template_version`, `version_number`, `expected_version_id`, `expected_revision`, `operation_key`. Для первого документа без версии ожидаемые идентификатор и ревизия равны 0. Конфликт состояния или повтор ключа с изменённым телом возвращает 409. Точный повтор возвращает ту же версию. Источник версии назначается сервером; переданные клиентом поля происхождения не меняют его. Обычная загрузка через существующий маршрут версий получает `origin=registered_external`.

Печать использует сохранённые проект, адрес, участников, подписантов, профиль и реквизиты связанных версий. Для старой версии без снимка проекта возвращается 409 с предложением подготовить новую версию. Подмена снимка текущими реквизитами проекта не выполняется. Поддержаны АОСР, акты разбивки осей, геодезической основы, конструкций и участков сетей. Схемы и иные внешние документы регистрируются штатной загрузкой.

Пределы генерации: снимок до 1 МиБ, PDF до 100 страниц и 25 МиБ. Удалённые ресурсы и исполнение PHP в PDF отключены. Динамические значения экранируются. Ограничение пакета: до 200 документов, 25 МиБ на файл и 64 МиБ суммарно. Для каждого файла проверяются область организации, версия манифеста и SHA-256; при расхождении комплект не выгружается. В печатный реестр не попадают пути S3.

Связь с архивом требует также `legal_archive.create`. Файл передаётся через существующий реестр и проверку загрузки архива. Источник архива — документ ИТД, а metadata версии содержит точную версию ИТД и её хеш. Загрузка выполняется вне транзакции записи связи: при её сбое повтор восстанавливает связь с уже сохранённой версией. Чужой источник/проект, изменённый файл или версия, не прошедшая обработку, не связываются как готовые.

Дальнейшие действия выполняются в существующем процессе юридического архива: регистрация бумажного оригинала отличается от проверки электронной подписи. Бумажная регистрация не является криптографической проверкой; внешняя электронная подпись остаётся ожидающей проверки до подтверждения доверенным провайдером. Отключённый провайдер не даёт успешного статуса. Изменение содержания или текущей версии во время регистрации отклоняется.

Карта полей и источников: `executive-document-print-field-map.md`. Проверка на реальном обезличенном комплекте ПТО остаётся отдельной приёмкой T16/T28. PDF-шаблоны имеют статус кандидатов в официальном каталоге; наличие генератора не объявляет их прошедшими эту приёмку.
