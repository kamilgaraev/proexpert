# Матрица поддерживаемых форм РФ (строительный учёт и ИТД)

Документ фиксирует, какие формы продукт реально печатает или ведёт, по каким первоисточникам, какие поля и проверки есть в коде, чего нет, и что **не** подтверждено на живом комплекте. Это не юридическое заключение и не закрытие сверки T16 на реальном обезличенном комплекте ПТО.

Дата составления: 2026-09-22. Источники в репозитории: `docs/api/executive-document-print-field-map.md`, `docs/api/general-journal-1026-field-map.md`, `docs/api/material-consumption-m29.md`, `docs/api/contract-period-certificate.md`, каталог `official-document-catalog.v1.yaml`.

## Общий итог профильного рассмотрения

| Форма | Статус в продукте | Профильное рассмотрение на реальном комплекте |
| --- | --- | --- |
| КС-2 | Печать/экспорт из snapshot акта | **не проводилось** — живого обезличенного комплекта в репозитории нет |
| КС-3 | Печать/экспорт справки периода | **не проводилось** |
| КС-6а | Печать/экспорт накопительного журнала | **не проводилось** |
| Оперативный дневной отчёт | Экспорт согласованных записей журнала | **не проводилось** |
| Общий журнал 1026/пр | Бумажная подготовка (`paper_preparation`) | **не проводилось** |
| Акты ИД (АОСР, оси, геодезия, конструкции, сети) | Генерация PDF из `profile_data` версии | **не проводилось** |
| М-29 | Candidate-рендерер, снимок отчёта | **не проводилось** |

Пункт плана T16 «сверить правила поддерживаемых форм с первоисточниками РФ и профильным ПТО на одном реальном обезличенном комплекте» **остаётся открытым**.

---

## 1. КС-2 (акт о приёмке выполненных работ)

| | |
| --- | --- |
| **Основание** | Унифицированная форма № КС-2 (постановление Госкомстата РФ от 11.11.1999 № 100). Продукт не заявляет обязательность КС-2 для каждого договора; печать — из зафиксированных строк акта. |
| **Поля из snapshot** | Позиция сметы/работы, количество, цена без НДС, сумма, ставка НДС и сумма с НДС из `PerformanceActLine` / финансового основания на момент утверждения; стороны договора из замороженных party snapshot при экспорте. |
| **Проверки в коде** | Резерв количества, политика технической приёмки, конфликт остатка, неизменность утверждённого/подписанного основания при смене текущей сметы (`OfficialFormsSnapshotRegressionTest`, `PerformanceActFinancialBasisTest`). |
| **Чего нет** | Автоматическая юридическая квалификация формы как единственно допустимой; проверка полномочий подписантов вне Legal Archive; живая сверка бланка с бумажным комплектом объекта. |
| **Пример вывода** | PDF/XLSX через `OfficialFormsExportService` / preview актирования. |
| **Ограничения** | Воспроизведение из сохранённых значений; текущая смета после подписи не меняет snapshot. |

## 2. КС-3 (справка о стоимости выполненных работ и затрат)

| | |
| --- | --- |
| **Основание** | Унифицированная форма № КС-3 (постановление Госкомстата РФ от 11.11.1999 № 100). |
| **Поля из snapshot** | Состав включённых актов периода, накопления с начала работ и с начала года, итоги периода, статус draft/approved/signed, watermark черновика. |
| **Проверки в коде** | Уникальность состава, freeze при approve, неизменность после новых актов и при загрузке подписанного файла (`ContractPeriodCertificateTest`, `ActingWizardPartialAcceptanceTest`). |
| **Чего нет** | Автоматический расчёт оплаты; профильная сверка на реальном комплекте. |
| **Пример вывода** | PDF/XLSX одной выборки `exportDataset` + checksum. |
| **Ограничения** | Черновик помечен; подписанный файл хранится отдельно от черновой печати. |

## 3. КС-6а (журнал учёта выполненных работ)

| | |
| --- | --- |
| **Основание** | Унифицированная форма № КС-6а (постановление Госкомстата РФ от 11.11.1999 № 100). |
| **Поля из snapshot** | Месячные группы периода (включая 13 месяцев через границу года), факт (`CompletedWork`), актировано (утверждённые/подписанные строки), остатки; строки с одинаковым наименованием и разными ключами сметы не сливаются. |
| **Проверки в коде** | `OfficialFormsPeriodRegressionTest::test_ks6a_fills_thirteen_months_keeps_unacted_fact_and_same_title_keys`. |
| **Чего нет** | Подмена оперативного дневного отчёта или полного журнала 1026/пр. |
| **Пример вывода** | Экспорт договора, шаблон `estimates.exports.ks6a`. |
| **Ограничения** | Период задаётся запросом; незакрытый месяц с фактом без акта сохраняет fact > acted. |

## 4. Оперативный дневной отчёт

| | |
| --- | --- |
| **Основание** | Внутренний оперативный отчёт по согласованным записям журнала работ; **не** является формой КС-6а и **не** является общим журналом по 1026/пр. |
| **Поля из snapshot** | Записи журнала за период, объёмы, исполнители по данным согласованных entry. |
| **Проверки в коде** | Переименование ярлыков и путей экспорта в T20; отдельные тесты журнала/экспорта. |
| **Чего нет** | Нормативный статус бланка Госкомстата; электронный журнал надзора. |
| **Пример вывода** | `POST .../export/ks6`, каталог `exports/journal/ks6/`, имена `WorkRegister_*`. |
| **Ограничения** | Старые пути сохранены; не выдавать за КС-6а. |

## 5. Общий журнал работ (приказ Минстроя № 1026/пр)

| | |
| --- | --- |
| **Основание** | Приказ Минстроя России от 02.12.2022 № 1026/пр, приложения № 1–2; официальная публикация [0001202212300009](https://publication.pravo.gov.ru/document/0001202212300009); действие с 01.09.2023 до 01.09.2029. |
| **Поля из snapshot** | Титул, представители, разделы 1–6 (ИТР, спецжурналы, хронология работ, строительный контроль, реестр ИД, госнадзор) — см. `general-journal-1026-field-map.md`. |
| **Проверки в коде** | Неизменяемость утверждённой редакции, режим только `paper_preparation`, отказ `electronic` 422, подписи через Legal Archive paper/verified. |
| **Чего нет** | XML-схема Минстроя, УКЭП каждой записи, регистрация в органе надзора, хранение на весь срок эксплуатации. |
| **Пример вывода** | PDF бумажной подготовки `1026-paper-v1`. |
| **Ограничения** | Подготовка бумаги ≠ ведение электронного общего журнала. |

## 6. Акты исполнительной документации (приказ Минстроя № 344/пр)

| | |
| --- | --- |
| **Основание** | Приказ Минстроя России от 16.05.2023 № 344/пр в редакции приказа № 369/пр от 23.06.2025 (с 01.03.2026). Бланки приложений № 1–5 сверены с локальным сканом и картами полей; URL публикаций — см. `executive-document-print-field-map.md`. |
| **Поддерживаемые печатные профили** | `geodetic_base_acceptance_act`, `axis_layout_act`, `hidden_work_act` (АОСР), `responsible_structure_act`, `engineering_network_section_act`. |
| **Поля из snapshot** | `profile_data` версии + реквизиты проекта/документа/подписантов + `relations` (`ExecutiveDocumentRelationSnapshot`). Полная таблица — в field-map. |
| **Проверки в коде** | Обязательные поля профиля, условия применимости подписантов, evidence/requirements, freeze версии, печать из конкретной версии шаблона (`ExecutiveDocumentRenderTest`, requirements/T16 suite). |
| **Чего нет** | Автоматический вывод «работы соответствуют»; проверка юридической силы подписи вне поддержанных форматов Legal Archive; CAD/схемы как собственный чертёж. |
| **Пример вывода** | PDF подготовки / пакет комплекта; эталонные страницы в локальных PDF QA T19. |
| **Ограничения** | Наличие файла ≠ нормативная проверка содержания. Редакция правил не меняет уже переданный манифест. |

## 7. М-29 (отчёт о расходе основных материалов)

| | |
| --- | --- |
| **Основание** | Типовая межотраслевая форма № М-29 (учёт расхода материалов в строительстве). В каталоге: `official_material_usage_m29`, публикация **candidate** (renderer 1.1.0). |
| **Поля из snapshot** | Норма × принятый объём, факт расхода, отклонение, основание нормы, период/объект; JSONB freeze после approve. |
| **Проверки в коде** | Версии норм, идемпотентность фактов, смешанные единицы только с явным коэффициентом, неизменность signed после rate v2 (`MaterialConsumptionStatementTest`). |
| **Чего нет** | Полная юридическая публикация формы; подмена складских М-11/списаний. |
| **Пример вывода** | Снимок отчёта + candidate PDF renderer. |
| **Ограничения** | Складской отпуск и нормативный расход — разные сущности. |

## Связанные проверки без бланка формы

| Тема | Что проверено кодом | Ограничение |
| --- | --- | --- |
| Границы орг/проект, bulk чужих ID | `CompletedWorkScopeRegressionTest`, `CompletedWorkBulkScopeTest` | UI не считается защитой |
| Конкурентный резерв / retry | `ActingQuantityConcurrencyTest`, journal/act idempotency | — |
| Сквозной сценарий 100→80/20→60+20→ИД v2 | `ConstructionAccountingLifecycleTest` | Не заменяет живой комплект ПТО |
| Ролевой UI | Админ-тесты формы факта, мастера акта, ПТО (см. progress T24–T25, T28) | Полный браузерный обход пяти ролей в T28 не выполнялся без поднятия dev-сервера |

## Честные границы

1. Сверка с первоисточниками по документам в репозитории и ранее зафиксированным URL/сканам **повторно зафиксирована** в этой матрице; новые нормативные выводы «соответствует полностью» не делались.
2. Профильное рассмотрение ПТО на реальном обезличенном комплекте **не проводилось** — комплекта в репозитории нет.
3. T16 checkbox про реальный комплект **не закрывать**.
