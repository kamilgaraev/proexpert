# Единицы загрузки складских ячеек

## Проблема

API суммирует количества материалов в ячейке без учёта единиц измерения. Поэтому килограммы, штуки и метры могут образовать одно число и ложный процент загрузки. Поля `capacity` и `max_weight` также выводятся без понятных единиц.

## Контракт

- Для пустой ячейки `stored_quantity` равен `0`, а процент загрузки может быть `0`, если задан лимит количества.
- Для одной единицы измерения API возвращает сумму, `measurement_unit`, разбивку `quantity_breakdown` и корректный процент загрузки.
- Для нескольких единиц или материала без единицы API не складывает несовместимые значения: `stored_quantity` и `current_utilization` равны `null`, а причины отражаются флагами и разбивкой.
- `capacity` трактуется как лимит количества в единице хранимого материала. `max_weight` всегда показывается в килограммах.
- Старые безъячеечные остатки, адресованные кодом ячейки, входят в тот же расчёт.

## Проверки

- Один материал в кг.
- Два материала в разных единицах.
- Материал без единицы измерения.
- Пустая ячейка и прежний остаток по коду.
- Отображение единиц, смешанного состояния и пояснений формы в админке.
