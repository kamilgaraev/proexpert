# Синтетические native-контроли дома

Это регрессионные входы для реальных `simulateInput` и `WorkPlanCompiler` с отложенным нормативным pin. Они не являются snapshot сессии85, извлечением147 фактов из её PDF, экспертной калибровкой или готовым BOM. Числовые доказательства явно синтетические; adapter находится только в tests/Support.

`known-inputs` задаёт полный набор измерений этого контрольного примера, включая H400мм. `missing-height` удаляет только H балки: глубина земляных работ0.5м не заменяет H. `source-conflict` сохраняет независимые400/600мм и конфликт. `many-entities` содержит64 отдельные балки для проверки identity и отсутствия перезаписи объёмов. Во всех случаях явно выбраны10 разделов.

Формулы oracle заданы независимо: балка10×0.25×0.4=1м³, плита40×0.08=3.2м³, земляные работы40×0.5=20м³. Объёмы разных объектов не суммируются в общий фундамент: пространственное разделение и полнота состава не подтверждены. Трассы35/20/180/6м, радиаторы3шт и оборудование6шт — входные числа контролей. Их наличие не доказывает остальные работы разделов.

Manifest фиксирует отдельные SHA256 входов и oracle. Adapter получает только prediction DTO, читает только input и никогда не видит expected. `oracle-canary` меняет ожидаемую работу, сохраняя вход: метрика должна показать0, а prediction остаться прежним. Это проверяет отсутствие утечки oracle.

Oracle требует минимальные семантические кандидаты девяти покрываемых разделов. Отсутствующий equipment package остаётся явным пробелом. Пустые ресурсы, неизвестные цены и служебные cost0 не считаются подтверждёнными материалами или бесплатной сметой. `estimate_complete`, `accuracy_calibrated` и `paid_actions_enabled` остаются false. Цена0 в отчёте — стоимость бесплатного контрольного исполнения, не стоимость строительства.

Этот corpus не проверяет PDF extraction, нормативный подбор, подтверждённые цены, сценарий, apply или XLSX. Соответствующие интеграционные проверки и полная экспертная приёмка остаются отдельными требованиями. Production QA run и общий лимит не читаются и не меняются; DB и HTTP в этом контроле запрещены.
