# Geometry fixtures

`simple-house.dxf` is an original synthetic R2000 fixture authored for МОСТ. It contains a millimetre drawing with LINE, closed LWPOLYLINE and TEXT entities.

`simple-house.dwg` was generated only from that fixture with the official GNU LibreDWG 0.13.4 `dxf2dwg` executable:

```text
dxf2dwg -o simple-house.dwg simple-house.dxf
```

No third-party drawing content is included. LibreDWG is GPL-3.0-or-later; the fixture is test data generated by the separate CLI and is not linked with application code.

`native-dimension-3000mm.dxf` is an original synthetic R2010 fixture generated with the hash-pinned `ezdxf==1.4.4` from `docker/geometry/requirements.lock`. Its model space contains a LINE from `(0, 0)` to `(3000, 0)` and a rendered linear DIMENSION; `$INSUNITS=4` explicitly declares millimetres. The expected native dimension is **3000 mm**. This standalone chain proves neither room area nor wall geometry.

`NativeCadProcessingPostgresTest` exercises the real CAD worker/provider, production processor, atomic PostgreSQL publication, scoped evidence and replay. It requires `MOST_CAD_TEST_PYTHON` to identify the installed pinned geometry Python runtime. It does not substitute a recorded parser response. Windows runs use the existing testing-only bounded process path; Linux still requires the existing sandbox. This case does not qualify DWG conversion, production runtime integrity or a calibrated estimate corpus.
